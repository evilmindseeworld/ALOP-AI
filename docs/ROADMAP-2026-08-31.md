## Done since the last roadmap

**Speed.** Six awaited round trips before the first token became two
(`7aef5a3`). The search fan-out got the same whip the council already had, and
stopped being as slow as its slowest provider — 8014ms to 608ms, 15 sources
kept (`3e7ffaa`). A search cache that survives a deploy: two-tier, fail-open,
read on a 400ms leash (`73694b5`). The screen stops being blank during search,
reusing the activity-trail events rather than inventing a second channel
(`d8f8d28`).

**Cold start, for free.** Render's free tier sleeps after 15 minutes and the
next visitor paid 22.5 seconds — larger than every code optimisation combined,
and landing on whoever arrives at a quiet moment. A GitHub Actions cron pings
`/health` every 10 minutes. Unmetered on public repos, and 750 free instance
hours covers one service staying awake. **One service only** — a second would
exhaust the allowance mid-month.

**98 KB off the sign-in page** (`9646d47`). The markdown renderer and
framer-motion were downloaded by people looking at a login form. The real find
was that lazy-loading the button achieved nothing on its own: `manualChunks`
had bundled framer-motion with animejs, which is imported eagerly, so the
shared chunk stayed on the critical path. The only symptom was one
`modulepreload` line in the built HTML.

**Legal, rewritten against the code** (`00daf6a`, `94dda0c`). Both documents
were live and wrong. The contact address was `alopai@example.com` — the address
a deletion request legally has to reach. The subprocessor list named seven
services; the code sends user content to fourteen, and omitted Ollama, which
receives every message anyone sends. IP addresses were stored and undisclosed.
Added: legal bases, transfers, a retention table, GDPR rights, a full CCPA/CPRA
section, and a minimum age of 13 (16 in the EEA/UK) stated **at sign-up**, not
only inside a linked page.

**All four font families self-hosted** (`94dda0c`). "Self-host the Google font"
would have fixed nothing on its own: `index.html` loaded Inter, which renders
nowhere, while the fonts that do render came from three `@import` lines buried
in `tokens.css` pointing at two CDNs. Verified in a browser — zero requests to
`fonts.googleapis.com`, `fonts.gstatic.com` or `api.fontshare.com`.

**Audit retention.** `audit_logs.ip_address` was written on every action and
nothing ever deleted a row. Now 90 days, swept every 200 writes because the
free tier has no scheduler.

**Closed out from the last roadmap.** The cmdk swap was attempted, rejected on
evidence, and the dead dependency deleted (`64dccce`). `SignInPage.css` was
folded into the guarded manifest and immediately surfaced six duplicates
(`088386d`); the real ones were merged (`71b2639`). Tool-loop numbers now go to
the database rather than stdout (`0ba67d8`). The "no prices displayed" bug was
the page reader cutting the document above the price (`6c52f70`).

   domain row shows an **ALERT / VERIFY CONTACTS** badge. Miss the 15-day
   window and `alop-ai.com` stops resolving, which makes every other item on
   this page irrelevant. The mail is in the registrant inbox.

2. **Clerk production cutover.** The instance exists and DNS is correct on the
   authoritative nameservers; Clerk's own checker is lagging. Watch for `200`:

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" https://clerk.alop-ai.com/v1/environment
   ```

   Then, **and not before** — swapping while that certificate does not exist
   takes the live site down:
   - Vercel `VITE_CLERK_PUBLISHABLE_KEY=pk_live_…` **and redeploy** (Vite bakes
     env vars in at build time; changing the variable alone does nothing)
   - Render `CLERK_SECRET_KEY=sk_live_…`

   The three development-instance users do not migrate. Expected.

3. **Stripe price IDs.** `STRIPE_PRICE_MONTHLY` and `STRIPE_PRICE_YEARLY` must
   point at **AED 30/month** and **AED 280/year**. If they do not,
   `/api/billing/prices` returns 503 and the upgrade path hides itself — a
   product nobody can pay for. The Terms now state both prices publicly, so
   Stripe has to match the page.

4. **Migrations.** `004_rate_limits.sql`, `005_search_cache.sql`,

## Three things that will bite if forgotten

**Do not scale Render past one instance** without setting
`RATE_LIMIT_STORE=postgres` first. The in-memory store is per-process, so every
limit multiplies by the instance count, and scaling is a dropdown — no deploy,
no review, nothing that flags it. The boot log states which store is active.

**Do not add a second free Render service** while the keep-warm cron runs. The
free tier allows 750 instance-hours a month against a ~730-hour month; one
service awake continuously fits, two do not, and the allowance runs out
mid-month rather than failing loudly.

**Read the cascade baseline diff before regenerating it.** Strip the element
indices first: a raw diff that does NOT shrink when indices are stripped means
something structural moved rather than renumbered. That check has now caught
two real regressions — a stagger that silently deleted the app's only shimmer,
and a font change that would have stopped the guard covering the sign-in card.

## The pattern worth keeping

Three separate things this week looked finished and were not, and the same
check caught all three: **read the built output, not the source.**

The CORS fix read correctly and broke every preview deployment. The
lazy-loaded button read correctly and still shipped framer-motion on the
critical path. "Self-host the Google font" read as one `<link>` and was
actually four families across two CDNs. In each case the source was persuasive
and the artefact was the truth.

The privacy policy was the same failure in prose: it described a system that
had drifted three vendors and one identifier away from what the code did.
